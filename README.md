
# A/B-тест новой формы оплаты ЖКХ

## О проекте
Анализ A/B-теста новой формы оплаты ЖКХ с автозаполнением реквизитов. Цель — оценить влияние новой формы на конверсию в успешную оплату.

## Этапы анализа
- Исследовательский анализ данных (EDA)
- Очистка и проверка качества данных
- Анализ конверсии на этапах воронки
- Сравнение групп A и B
- Статистическая проверка гипотез
- Подготовка рекомендаций

## Результаты
- Конверсия группы A: 65,73%
- Конверсия группы B: 80,40%
- Абсолютный прирост: 14,67 п.п.
- Относительный прирост: 22,3%
- p-value: 1,53 × 10⁻¹⁰

## Инструменты
Python, pandas, matplotlib, seaborn, SciPy, Jupyter Notebook

## Вывод
Результаты анализа свидетельствуют в пользу внедрения новой формы оплаты. После запуска рекомендуется отслеживать конверсию и количество ошибок при проведении платежей.
